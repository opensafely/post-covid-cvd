# Script overview

This repository contains the following scripts:

- **protocol/**
  - **post-covid-events-ehrql.pdf**: The common protocol for all post-covid-events analyses.
  - **post-covid-events-cvd.pdf**: The outcome-specific protocol detailing cardiovascular-specific considerations.
- **codelists/**
  - **\*.csv**: Codelists for each variable defined in this study, downloaded by `opensafely codelists update`.
  - **codelists.json**: JSON list of codelists automatically generated by `opensafely codelists update`.
  - **codelists.txt**: User defined list of codelists for this study.
- **project.yaml**: The project pipeline used for executing the code and detailing dependencies. This file should not be edited directly. To make changes, edit and run [create_project_actions.R](./analysis/create_project_actions.R).
- **lib/**
  - **active_analyses.rds**: Reference file containing the details for all analyses to be run as part of this study.
- **analysis/**
  - **utility.R**: Generic utility functions for the analysis pipeline, including `display()` and `roundmid_any`/
  - **create_project_actions.R**: R script to automatically generate `project.yaml` file. 
  - **study_dates.R**: R script to create [study_dates.json](./output/study_dates.json), which stores the date-specific metadata (e.g. the start dates of the phases of the study, vaccine dates).
  - **active_analyses/**
    - **active_analyses.R**: Creates a reference file called [active_analyses.rds](./lib/active_analyses.rds)
    - **fn-add_analysis.R**: Function to add an analysis to [active_analyses.rds](./lib/active_analyses.rds)
  - **dataset_clean/**
    - **dataset_clean.R**: Core script for cleaning datasets.
    - **fn-modify_dummy.R**: Function to modify dummy data to test pipeline fully.
    - **fn-preprocess.R**: Function to apply preprocessing steps, such as variable formats.
    - **fn-inex.R**: Function to apply study inclusion/exclusion criteria.
    - **fn-qa.R**: Function to apply quality assurance criteria.
    - **fn-ref.R**: Function to set reference categories for variables and handle missingness.
  - **dataset_definition/**
    - **dataset_definition_prevax.py**: Generates the pre-vaccination cohort dataset using [`dataset_definition_cohorts`](./analysis/dataset_definition/dataset_definition_cohorts.py) and adding cohort-specific elements.
    - **dataset_definition_unvax.py**:Generates the unvaccinated cohort dataset using [`dataset_definition_cohorts`](./analysis/dataset_definition/dataset_definition_cohorts.py) and adding cohort-specific elements.
    - **dataset_definition_vax.py**: Generates the vaccinated cohort dataset using [`dataset_definition_cohorts`](./analysis/dataset_definition/dataset_definition_cohorts.py) and adding cohort-specific elements.
    - **dataset_definition_cohorts.py**: Defines the common elements of all cohorts using user specified index dates, cohort start date and cohort end date. 
    - **dataset_definition_dates.py**: Generates a dataset of key dates that is used by all other `dataset_definition_*.py` scripts.
    - **variable_helper_functions.py**: Defines ehrQL functions for variable creation.
    - **variables_cohorts.py**: Creates a dictionary used for defining cohort variables.
    - **variables_dates.py**: Creates a dictionary used for defining date variables.
    - **codelists.py**: Creates codelist variables that can be accessed by [`variables_cohorts.R`](./analysis/variables_cohorts.py).
  - **make_output/**
    - **make_aer_input.R**: Prepares input dataset for absolute excess risk analysis.
    - **make_other_output.R**: Combines outputs across cohorts and applies rounding to generate non-model output release files.
    - **make_model_output.R**: Combines outputs across cohorts and applies rounding to generate model output release files.
  - **model/**
    - **make_model_input.R**: Prepares input dataset for Cox modelling.  
    - **fn-check_vitals.R**: Function to check the essential components of the input dataset for Cox modelling.  
    - **fn-prepare_model_input.R**: Function to aid preparation of input dataset for Cox modelling. 
  - **table1/**
    - **table1.R**: Generates Table 1, which details patient characteristics.
  - **table2/**
    - **table2.R**: Generates Table 2, which details the sample size, the number of outcome events and exposed/unexposed person time.
  - **venn/**
    - **venn.R**: Generates input dataset for Venn diagrams that detail the data sources where each outcome is identified.

**flow_output_midpoint6.csv**

A concatenation of the flow descriptors generated by [`fn-inex.R`](./analysis/dataset_clean/fn-inex.R) and [`fn-qa.R`](./analysis/dataset_clean/fn-qa.R), the inclusion/exclusion function and the quality assurance function.

| Variable                   | Description                                                                   |
|----------------------------|-------------------------------------------------------------------------------|
|     Description            | the inclusion/exclusion/quality criteria applied (Input: start of new cohort) |
|     N_midpoint6            | the total number of people remaining in the dataset                           |
|     removed_derived        | the total number of people removed from this criteria                         |
|     flow                   | an incremental counter of criteria applied so far in this dataset             |
|     cohort                 | cohort used for the analysis                                                  |
